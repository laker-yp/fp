take n xs	保留前 n 个

**take**:从 list 前面取出前 n 个元素

take 3 [1,2,3,4,5]--输出[1,2,3]

**drop**：把前 n 个元素丢掉，返回剩下的 list。

drop 2 [1, 2, 3, 4, 5]--输出[4,5]
