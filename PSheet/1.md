## The Terminal

[vLab](https://vlab.oc1.aws.cs.bham.ac.uk/) 包含一个 Linux terminal system。  
你可以用它来：

- 创建 files 和 directories
- 编译 source modules
- 运行 programs

如果你不熟悉 Linux terminal，这第一个练习会带你了解一些最基础的 commands。

1. 要打开 terminal，从 [vLab](https://vlab.oc1.aws.cs.bham.ac.uk/) launcher 中选择 `"Terminal"`。  
   然后你应该会看到一个 command prompt，并且有一个闪烁的 cursor。

1. 命令 `pwd` 是 `"print working directory"` 的意思。  
   输入它并按 enter，会显示你当前在系统中的位置。

1. 你可以用 `mkdir` 创建一个新的 directory。  
   例如，试试：

   ```bash
   mkdir scratch
   ```

   这会创建一个新的 `scratch` directory。

1. 你可以用 `cd` 切换 directories。  
   试试：

   ```bash
   cd scratch
   ```

   这会进入你刚刚创建的 directory。

1. 创建 new files 有很多方式。  
   一个简单的方法是使用 `touch` command。  
   试试：

   ```bash
   touch foo.txt
   ```

   这会创建一个空的 text file。

1. 你可以用 `ls` command 列出当前 directory 中的 files。  
   现在试一下，你应该能看到刚才创建的 file。

   如果想看到更多 file information，可以试试：

   ```bash
   ls -l
   ```

   它会显示例如 creator、size、date 和 time of creation 等信息。

1. 如果想把 hidden files 也显示出来，可以使用：

   ```bash
   ls -la
   ```

   hidden files 指的是以 `"."` 开头的 files。

   注意：有两个特殊的 hidden directories：

   - `.` 表示 current directory
   - `..` 表示 parent directory

   你可以试着 `cd` 到这些 directories，观察会发生什么。

1. `cd ..` 会进入 parent directory。

1. `cd ~` 或者单独输入 `cd`，都会回到你的 home directory。

1. `cd -` 会回到你执行上一次 `cd` command 之前所在的 directory。

1. 命令：

   ```bash
   cp foo.txt myfoo.txt
   ```

   会创建一个新的 file `myfoo.txt`，内容与已有的 file `foo.txt` 相同。

   建议你像这样使用 `cp` 来复制 files，这样就可以在副本上进行自己的修改和实验，而不会破坏原始文件。

1. 命令：

   ```bash
   rm myfoo.txt
   ```

   会从当前 directory 中删除 file `myfoo.txt`。

1. 命令：

   ```bash
   mv myfoo.txt MyNewLife.hs
   ```

   会把 file `myfoo.txt` 重命名为 `MyNewLife.hs`。

1. 命令：

   ```bash
   mv myf<tab>
   ```

   如果当前 directory 中存在唯一匹配的文件名，它会自动补全名称。

   这种 `<tab>` completion 可以用于任何 command，包括 `cd`。

   `<tab>` key 在不同键盘上可能有不同标志。  
   例如在 Mac 上，它看起来大约像 `->|`。

1. 命令：

   ```bash
   grep <string> *.md
   ```

   会查找所有提到这个 string 的 `md` files。

   例如，如果你在 lecture notes directory 中，可以使用：

   ```bash
   grep type *.md
   ```

   来查找哪些 lecture notes 包含单词 `type`。

   这对于在 lecture notes 中找信息很有用。

   `grep` 代表 global regular expression search and find。

1. 命令：

   ```bash
   find . -name myfoo.txt
   ```

   会搜索 current directory 以及它的 subdirectories，尝试找到你的 file。

1. 命令：

   ```bash
   find ~ -name "*foo.txt"
   ```

   会搜索你的 home directory 以及它的 subdirectories，找到任何文件名以 `foo.txt` 结尾的 file，包括 `myfoo.txt`。

   你也可以这样写：

   ```bash
   find .. -name "*foo*.txt"
   ```

   这里的 stars `*` 是 wild cards。

1. 你可以使用键盘上的 up 和 down arrows 找到你之前输入过的 commands，然后再次运行它们。

1. 你可以学习 [more commands](https://duckduckgo.com/?t=ffab&q=bash+summary+of+commands&atb=v358-1&ia=web)，让你的操作更轻松。

后面的 exercises 中我们还会遇到更多 commands。

目前为止的 Summary：

```text
pwd, mkdir, cd, touch, ls, cp, rm, mv, grep, find
```

## Cloning the course repository

Git 是目前最流行的 version control systems 之一。

它用于跟踪 files 在 development process 中的 revisions 和 changes。  
你的 module team 使用这个 system 来 update 和 revise course materials。

我们的第一步是在 [vLab](https://vlab.oc1.aws.cs.bham.ac.uk/) 中设置对课程 GitLab repository 的访问权限。

1. 登录 [vLab](https://vlab.oc1.aws.cs.bham.ac.uk/)

1. 打开 terminal

1. 运行命令：

   ```bash
   setup-git
   ```

1. 这个 script 会打印出一个 public key。  
   你必须手动把它复制到 GitLab server。

   打开：

   ```text
   https://git.cs.bham.ac.uk/-/user_settings/ssh_keys
   ```

   然后把 script 输出的内容粘贴到标有 **Key** 的框里。

1. 你也可以在标有 **Title** 的框里给你的 key 起一个名字，例如：

   ```text
   vLab Key
   ```

1. 点击 `Add Key`。

1. 回到 [vLab](https://vlab.oc1.aws.cs.bham.ac.uk/) terminal，确保你现在位于 `/jupyter/work/` folder，然后运行：

   ```bash
   git clone git@git.cs.bham.ac.uk:fp/fp-learning-2025.git
   ```

   这会把 course repository 复制到你的 [vLab](https://vlab.oc1.aws.cs.bham.ac.uk/) instance。

1. 当 cloning process 完成后，你应该会在 working folder 中看到一个新的 folder：

   ```text
   fp-learning-2025
   ```

   在 Linux 中，folders 更常被称为 directories。

1. 使用你上面学到的 Linux commands 探索这个 resulting directory。

   **Note**：如果你因为某些原因需要查看上面步骤生成的 public ssh key，它被存储在这个 file 中：

   ```text
   /jupyter/work/.ssh/gitlab.pub
   ```

   你可以用下面的 command 查看这个 file 的内容：

   ```bash
   cat /jupyter/work/.ssh/gitlab.pub
   ```

   `cat` command 的作用就是在 terminal 中显示一个 file 的内容。

## Running and Compiling the Game of Life

本周 lecture 中讨论的 Game of Life program 的 source code 可以在下面这个 directory 中找到：

```text
/files/LectureNotes/Sections
```

在 repository 中的对应路径是：

```text
fp-learning-2025/files/LectureNotes/Sections
```

1. 我们先创建一个文件副本来操作。  
   复制 file 时，我们使用 `cp` command。

   注意下面 `cp` command 中使用了 parent directory `..`：

   ```bash
   cd /jupyter/work
   mkdir life
   cd life
   cp ../fp-learning-2025/files/LectureNotes/Sections/Life.hs .
   ```

   注意最后一个 command 末尾的 `.` 非常关键。  
   它告诉 `cp` command：destination folder 是 current one。

1. 我们可以直接用下面的 command 运行这个 program：

   ```bash
   runhaskell Life.hs
   ```

1. 用 `Ctrl-c` 停止 program。

1. 另一种方式是把 source 编译成 executable，这样之后就可以直接从 system 中运行它。

   这可以通过 `ghc` 的 `"make"` option 完成。  
   它会负责 compiling、linking，以及包含所有 dependencies。

   ```bash
   ghc --make Life.hs
   ```

1. 我们可以通过输入下面命令运行生成的 executable：

   ```bash
   ./Life
   ```

## Making and Interpreting A Haskell Source module

1. 在你选择的 directory 中创建一个名为 `foo.hs` 的新 file。  
   你可以用 terminal，也可以用 file browser。

1. 添加下面的内容：

   ```hs
   double :: Int -> Int
   double x = x + x
   ```

1. 打开一个新的 terminal window。

1. 运行：

   ```bash
   ghci
   ```

   来启动 Haskell interpreter。

1. 用下面方式加载 new file：

   ```text
   Prelude> :l foo.hs
   [1 of 1] Compiling Main             ( foo.hs, interpreted )
   Ok, one module loaded.
   ```

1. 用你喜欢的数字运行 function `double`：

   ```text
   *Main> double 6
   ```

## Inspecting Some Types in Ghci

Haskell 是一种 strongly typed language。  
这意味着 language 中的所有 expressions 都会被分配一个 type，用来描述它们可以如何被使用。

我们可以使用 Haskell interpreter `ghci` 来查看各种 expressions 的 type。

在 `ghci` 中输入：

```text
:t True
```

你应该会看到输出：

```text
True :: Bool
```

这表示 expression `True` 是一个 boolean。

使用同样的方法找出下面 expressions 的 types：

1. `not (not (not False))`

1. `(True,False)`  
   参考 Section 3.4 of Programming in Haskell

1. `['a', 'b', 'x']`  
   参考 Section 3.3 of Programming in Haskell

1. `[(3,4),(4,6)]`

1. `(++)`  
   这个 type 有什么奇怪的地方？  
   参考后面会讨论的 `"polymorphic functions"`。
