# 一、最高命中率：Magic Square 原题变体

## 1. isMagicSquare 标准答案

```haskell
isMagicSquare :: [[Int]] -> Bool
isMagicSquare xs = all (== target) sums
  where
    n = length xs
    target = sum (head xs)

    rows = xs

    cols = [[ row !! i | row <- xs ] | i <- [0..n-1]]

    diag1 = [ xs !! i !! i | i <- [0..n-1]]

    diag2 = [ xs !! i !! (n - 1 - i) | i <- [0..n-1]]

    sums = map sum (rows ++ cols ++ [diag1, diag2])
```

---

## 2. isMagicSquare 笨方法版本

```haskell
isMagicSquare :: [[Int]] -> Bool
isMagicSquare square =
  rowsOK && colsOK && diag1OK && diag2OK
  where
    n = length square
    target = sum (head square)

    rowsOK =
      all (\row -> sum row == target) square

    colsOK =
      all (\i -> sum [ row !! i | row <- square ] == target) [0..n-1]

    diag1OK =
      sum [ square !! i !! i | i <- [0..n-1] ] == target

    diag2OK =
      sum [ square !! i !! (n - 1 - i) | i <- [0..n-1] ] == target
```

---

## 3. 判断所有行 sum 是否相等

```haskell
allRowsSameSum :: [[Int]] -> Bool
allRowsSameSum xs = all (== target) (map sum xs)
  where
    target = sum (head xs)
```

---

## 4. 判断所有列 sum 是否相等

```haskell
allColsSameSum :: [[Int]] -> Bool
allColsSameSum xs = all (== target) colSums
  where
    n = length xs
    target = sum [ row !! 0 | row <- xs ]
    colSums = [ sum [ row !! i | row <- xs ] | i <- [0..n-1] ]
```

---

## 5. 取主对角线 diagonal

```haskell
diagonal :: [[a]] -> [a]
diagonal xs = [ xs !! i !! i | i <- [0..n-1] ]
  where
    n = length xs
```

---

## 6. 取副对角线 antiDiagonal

```haskell
antiDiagonal :: [[a]] -> [a]
antiDiagonal xs = [ xs !! i !! (n - 1 - i) | i <- [0..n-1] ]
  where
    n = length xs
```

---

## 7. 返回 magic sum

```haskell
magicSum :: [[Int]] -> Int
magicSum xs = sum (head xs)
```

---

## 8. 返回 Maybe magic sum

```haskell
magicSumMaybe :: [[Int]] -> Maybe Int
magicSumMaybe xs
  | isMagicSquare xs = Just (sum (head xs))
  | otherwise        = Nothing
```

# 二、高命中率：矩阵 / 二维列表基础函数

## 9. transpose 矩阵转置

```haskell
transpose :: [[a]] -> [[a]]
transpose xs = [[ row !! i | row <- xs ] | i <- [0..n-1]]
  where
    n = length (head xs)
```

---

## 10. rowSums 所有行和

```haskell
rowSums :: [[Int]] -> [Int]
rowSums xs = map sum xs
```

---

## 11. colSums 所有列和

```haskell
colSums :: [[Int]] -> [Int]
colSums xs = map sum (transpose xs)
```

如果不想单独写 `transpose`：

```haskell
colSums :: [[Int]] -> [Int]
colSums xs = [ sum [ row !! i | row <- xs ] | i <- [0..n-1] ]
  where
    n = length (head xs)
```

---

## 12. diagonalSums 两条对角线的和

```haskell
diagonalSums :: [[Int]] -> (Int, Int)
diagonalSums xs = (sum diag1, sum diag2)
  where
    n = length xs
    diag1 = [ xs !! i !! i | i <- [0..n-1] ]
    diag2 = [ xs !! i !! (n - 1 - i) | i <- [0..n-1] ]
```

---

## 13. flatten 二维列表展开

```haskell
flatten :: [[a]] -> [a]
flatten xss = concat xss
```

不用 `concat`：

```haskell
flatten :: [[a]] -> [a]
flatten [] = []
flatten (xs:xss) = xs ++ flatten xss
```

---

## 14. isSquare 判断是不是 n by n

```haskell
isSquare :: [[a]] -> Bool
isSquare [] = False
isSquare xs = all (\row -> length row == n) xs
  where
    n = length xs
```

---

## 15. getColumn 取第 k 列

```haskell
getColumn :: Int -> [[a]] -> [a]
getColumn k xs = [ row !! k | row <- xs ]
```

---

## 16. getRow 取第 k 行

```haskell
getRow :: Int -> [[a]] -> [a]
getRow k xs = xs !! k
```

## 17. 判断某一行是否全相同

```haskell
allSame :: Eq a => [a] -> Bool
allSame [] = True
allSame (x:xs) = all (== x) xs
```

---

## 18. 判断某一列是否全相同

```haskell
colAllSame :: Eq a => Int -> [[a]] -> Bool

```

---

## 19. 判断某个玩家是否赢了

```haskell
hasWon :: Char -> [[Char]] -> Bool
hasWon player board =
  any lineWin linesToCheck
  where
    n = length board

    rows = board

    cols = [[ row !! i | row <- board ] | i <- [0..n-1]]

    diag1 = [ board !! i !! i | i <- [0..n-1]]

    diag2 = [ board !! i !! (n - 1 - i) | i <- [0..n-1]]

    linesToCheck = rows ++ cols ++ [diag1, diag2]

    lineWin line = all (== player) line
```

---

## 20. 判断棋盘是否满了

```haskell
boardFull :: [[Char]] -> Bool
boardFull board = all (/= ' ') (concat board)
```

---

## 21. 返回赢家 Maybe Char

```haskell
winner :: [[Char]] -> Maybe Char
winner board
  | hasWon 'X' board = Just 'X'
  | hasWon 'O' board = Just 'O'
  | otherwise        = Nothing
```

# 四、中高命中率：Maybe / Either 安全版本

## 22. safeIndex 安全取下标

```haskell
safeIndex :: Int -> [a] -> Maybe a
safeIndex _ [] = Nothing
safeIndex 0 (x:_) = Just x
safeIndex n (_:xs)
  | n < 0     = Nothing
  | otherwise = safeIndex (n - 1) xs
```

---

## 23. safeGet2D 安全取二维坐标

```haskell
safeGet2D :: Int -> Int -> [[a]] -> Maybe a
safeGet2D i j xs = do
  row <- safeIndex i xs
  safeIndex j row
```

---

## 24. safeDiagonal 安全取主对角线

```haskell
safeDiagonal :: [[a]] -> Maybe [a]
safeDiagonal xs = sequence [ safeGet2D i i xs | i <- [0..n-1] ]
  where
    n = length xs
```

# 五、中命中率：List Comprehension 常见写法

## 27. 所有坐标 positions

```haskell
positions :: [[a]] -> [(Int, Int)]
positions xs = [(i,j) | i <- [0..rows-1], j <- [0..cols-1]]
  where
    rows = length xs
    cols = length (head xs)
```

---

## 28. 取矩阵中所有偶数

```haskell
allEvenNumbers :: [[Int]] -> [Int]
allEvenNumbers xs = [ x | row <- xs, x <- row, even x ]
```

---

## 29. 找出大于 target 的坐标

```haskell
greaterThanPositions :: Int -> [[Int]] -> [(Int, Int)]
greaterThanPositions target xs =
  [ (i,j)
  | i <- [0..rows-1]
  , j <- [0..cols-1]
  , xs !! i !! j > target
  ]
  where
    rows = length xs
    cols = length (head xs)
```

---

## 30. replaceAt 替换列表某个位置

```haskell
replaceAt :: Int -> a -> [a] -> [a]
replaceAt _ _ [] = []
replaceAt 0 new (_:xs) = new : xs
replaceAt n new (x:xs) = x : replaceAt (n - 1) new xs
```

---

## 31. updateGrid 更新二维列表某个位置

```haskell
updateGrid :: Int -> Int -> a -> [[a]] -> [[a]]
updateGrid i j new grid =
  replaceAt i newRow grid
  where
    oldRow = grid !! i
    newRow = replaceAt j new oldRow
```

# 六、中命中率：递归版本押题

## 32. allEqual 递归版

```haskell
allEqual :: Eq a => [a] -> Bool
allEqual [] = True
allEqual [_] = True
allEqual (x:y:xs)
  | x == y    = allEqual (y:xs)
  | otherwise = False
```

---

## 33. sumRows 递归版

```haskell
sumRows :: [[Int]] -> [Int]
sumRows [] = []
sumRows (row:rows) = sum row : sumRows rows
```

---

## 34. transpose 递归版

```haskell
transposeRec :: [[a]] -> [[a]]
transposeRec [] = []
transposeRec ([]:_) = []
transposeRec xs = map head xs : transposeRec (map tail xs)
```

---

## 35. flatten 递归版

```haskell
flattenRec :: [[a]] -> [a]
flattenRec [] = []
flattenRec (xs:xss) = xs ++ flattenRec xss
```

# 七、低中命中率：更难一点的扩展

## 36. Latin Square 判断

```haskell
isLatinSquare :: Eq a => [[a]] -> Bool
isLatinSquare xs =
  isSquare xs && rowsOK && colsOK
  where
    firstRow = head xs

    rowsOK =
      all (\row -> sameElements row firstRow) xs

    colsOK =
      all (\col -> sameElements col firstRow) (transpose xs)

    sameElements as bs =
      all (`elem` bs) as && all (`elem` as) bs
```

---

## 37. Sudoku 行检查

```haskell
validSudokuRow :: [Int] -> Bool
validSudokuRow row =
  all (`elem` row) [1..9] && length row == 9
```

---

## 38. validSudoku 简化版

```haskell
validSudoku :: [[Int]] -> Bool
validSudoku board =
  rowsOK && colsOK
  where
    rowsOK = all validSudokuRow board
    colsOK = all validSudokuRow (transpose board)
```

---

## 39. rotate90 矩阵顺时针旋转

```haskell
rotate90 :: [[a]] -> [[a]]
rotate90 xs = [ reverse col | col <- transpose xs ]
```

---

## 40. symmetric 判断矩阵是否对称

```haskell
symmetric :: Eq a => [[a]] -> Bool
symmetric xs = xs == transpose xs
```
