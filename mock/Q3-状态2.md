# A区：Calculator 命令链

默认：

```haskell
import Control.Monad.State
import Control.Monad.Except

data Cmd = Stop
         | Store Int Cmd
         | Add Int Cmd
         | Sub Int Cmd
         | Mul Int Cmd
         | Div Int Cmd
         deriving Show
```

## A1. 基础命令链 runSimple

```haskell
runSimple :: Cmd -> State Int ()
runSimple Stop = return ()

runSimple (Store n next) = do
  put n
  runSimple next

runSimple (Add n next) = do
  modify (+ n)

runSimple (Sub n next) = do

  runSimple next
```

## A3. 执行命令列表

```haskell
data SimpleCmd = AddS Int | SubS Int | MulS Int | StoreS Int
  deriving Show

runOne :: SimpleCmd -> State Int ()
runOne (AddS n) = modify (+ n)
runOne (SubS n) = modify (subtract n)
runOne (MulS n) = modify (* n)
runOne (StoreS n) = put n

runCommands :: [SimpleCmd] -> State Int ()
runCommands [] = return ()

runCommands (c:cs) = do
  runOne c
  runCommands cs
```

## A8. 统计执行了多少条命令

状态是 `(当前值, 命令数量)`。

```haskell
type CalcCount a = State (Int, Int) a

runCount :: Cmd -> CalcCount ()
runCount Stop = return ()

runCount (Store n next) = do
  (_, count) <- get
  put (n, count + 1)
  runCount next

runCount (Add n next) = do
  (value, count) <- get
  put (value + n, count + 1)
  runCount next

runCount (Sub n next) = do
  (value, count) <- get
  put (value - n, count + 1)
  runCount next

runCount (Mul n next) = do
  (value, count) <- get
  put (value * n, count + 1)
  runCount next

runCount (Div n next) = do
  (value, count) <- get
  put (value `div` n, count + 1)
  runCount next
```

## C10. replaceTreeValuesFromList：用状态里的 list 中序替换树值

```haskell
replaceTreeValuesFromList :: Tree a -> State [b] (Maybe (Tree b))
replaceTreeValuesFromList Empty = return (Just Empty)

replaceTreeValuesFromList (Node l _ r) = do
  leftResult <- replaceTreeValuesFromList l
  case leftResult of
    Nothing -> return Nothing
    Just l' -> do
      xs <- get
      case xs of
        [] -> return Nothing
        y:ys -> do
          put ys
          rightResult <- replaceTreeValuesFromList r
          case rightResult of
            Nothing -> return Nothing
            Just r' -> return (Just (Node l' y r'))
```

## C11. Rose Tree：给所有 Leaf 编号

```haskell
data Rose a = Leaf a
            | Branch [Rose a]
            deriving Show

labelRoseLeaves :: Rose a -> State Int (Rose (Int, a))
labelRoseLeaves (Leaf x) = do
  n <- get
  put (n + 1)
  return (Leaf (n, x))

labelRoseLeaves (Branch xs) = do
  ys <- mapM labelRoseLeaves xs
  return (Branch ys)
```

---

## C12. Rose Tree：查找并统计访问步数

```haskell
findRoseCountSteps :: Eq a => a -> Rose a -> State Int Bool
findRoseCountSteps target (Leaf x) = do
  modify (+1)
  return (target == x)

findRoseCountSteps target (Branch xs) = do
  modify (+1)
  search xs
  where
    search [] = return False
    search (t:ts) = do
      found <- findRoseCountSteps target t
      if found
        then return True
        else search ts
```

# 最后一句

State 题的本质：

```haskell
do
  old <- get
  put / modify new
  recursiveResult <- recursiveCall
  return result
```

带失败处理的 State 题：

```haskell
if bad
  then return Nothing / Left error
  else do
    modify ...
    return (Just result / Right result)
```

Tree + State 题最重要的是顺序：

```haskell
根左右 = preorder
左根右 = inorder
左右根 = postorder
```
